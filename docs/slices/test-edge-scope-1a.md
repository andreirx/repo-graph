**D-TESA-02 — the token rule, exactly L07's words.** Split the repo-relative path at `/`, `.`, `_`, `-`; split each piece at CamelCase boundaries (lowercase letter or digit → uppercase letter; uppercase → uppercase followed by lowercase, so `XMLTest` → `XML`, `Test`); a token is a test word iff its ASCII-lowercase form is `test`, `tests`, `testing`, `tester` or `testutil`; the FIRST such token in path order is the reported word, as written.
