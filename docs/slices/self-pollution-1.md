# SELF-POLLUTION-1 — rmap must not measure its own exhaust

Status: SPECIFIED (2026-08-26) · Track: Usefulness-audit fix queue #1
(`docs/ROADMAP.md` § Usefulness audit v0.9.0; evidence run `smoke-runs/2026-08-25T22-41-37Z`).
CODE slice, small. Maturity: MATURE surfaces touched.

## 1. Problem (measured)

`rmap map` writes `*_MAP.md` / `MAP.md` sidecars into target repos. Three shipped surfaces then
measure that exhaust as if it were the reader's repo:

- **INDEX_DRIFT counts it** (OBSERVED): django `check --full` → `INCOMPLETE@Fresh`, exit 2, and a
  `run rmap refresh` nag in every footer — over "3,721 files changed", of which 3,721 are rmap's
  own MAP.md + 6 `.DS_Store`; leveldb: 144/144. Zero source changes. The drift surface built for
  honesty produces a false staleness verdict on repos rmap itself touched.
- **`docs list` catalogs it** (OBSERVED): 70–97% of "documents" are self-generated maps (django
  700/706, incl. gitignored `backend/bin/**` on glamCRM), while REAL docs are missed
  (django `docs/**.txt`, leveldb `doc/{impl,index,log_format,table_format}.md`) and `.env*`
  files are listed as `config` docs — `.env.test` even reaches amodx's orient Docs headline.
- **The seed corpus embeds it** (OBSERVED indirectly: config-file noise at probe rank-2).

Additionally (same audit, same slice since the surface is shared): INDEX_DRIFT downgrades check to
INCOMPLETE even when 0 INDEXED files changed (leveldb pre-fix: "144 files changed (0 indexed)").

## 2. Contract

1. **One classifier, one truth**: a shared `is_self_generated(path)` predicate (rmap's map
   sidecars: `MAP.md`, `*_MAP.md` matching the generator's naming, plus the `.rgr/` dir) lives in
   ONE place and is used by drift, docs inventory, and the seed corpus. Detection by the
   generator's own naming convention + the `[generated by rmap map]` marker already present in
   the files' first line — never a bare name-glob alone where the marker is checkable.
2. **INDEX_DRIFT**: self-generated files and `.DS_Store`-class OS noise are excluded from the
   changed-files count; the drift line reports what it excluded ("… +3,727 tool/OS files
   ignored") so nothing is silently hidden. **K=0 calibration**: when 0 INDEXED files changed,
   INDEX_DRIFT is `Pass` with the informational line — never `Incomplete`.
3. **`docs list`**: self-generated maps are EXCLUDED by default (`--include-generated` opts in;
   the excluded count is printed); `.env*` never classifies as a doc (secrets-adjacent, zero doc
   value) and never reaches orient's Docs line; `.txt`/`.rst` join the doc-extension set so
   django's `docs/**` and leveldb's `doc/*.md` render. Real-docs recall proven on both.
4. **Seed corpus**: `is_self_generated` paths and `.env*` are excluded from embedding (already-
   built stores refresh them out on next pass via the content-hash diff — no migration).
5. Byte-parity everywhere else; no schema change.

## 3. Stop conditions

Frozen: storage schema, exit-code semantics (the django INCOMPLETE→PASS change is the CONTRACT
being fixed, not an exit-semantics change), trust, LiveGraph/witness/reconciliation. If the
generated-marker check requires reading file contents on the drift path and that is measurably
hot on a 160k-file repo, name it and gate on extension+name first, marker only for ambiguity.
Never touch the operator's real state root. Do NOT commit.

## 4. Validation (SYNCHRONOUS; INCREMENTAL REPORT — binding)

- Unit: classifier (positive: MAP.md/x_MAP.md with marker; negative: a user's own MAP.md WITHOUT
  the marker is NOT excluded — name-collision honesty); drift exclusion + reporting; K=0 → Pass;
  docs default-exclusion + opt-in + count; `.env` never a doc; `.txt`/`.rst` admitted.
- LIVE isolated proofs: django — `check --full` goes INCOMPLETE→PASS (or FAIL only on its real
  reliability), drift line reports the exclusion, `docs list` surfaces `docs/**.txt` (>600) and
  drops the 700 maps; leveldb — `doc/impl.md` etc. render; glamCRM — `backend/bin/**` maps gone,
  orient Docs line free of `.env`. Byte-parity check on a repo with no self-generated files.
- Chunked cargo gates; consolidation witness green; dogfood green; logged smoke
  SMOKE_ONLY="django leveldb" green.

## 5. Definition of done

rmap never counts, catalogs, or embeds its own exhaust; drift verdicts reflect the reader's
changes only (and say what was ignored); real documentation renders; K=0 drift is a Pass; gates
green.
