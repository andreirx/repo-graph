# D-DGC1B-ARTIFACT-INTERPOLATION-1 — a Groovy alias-map entry whose GROUP segment is literal resolves to that group even when its artifact or version is interpolated; an interpolated group resolves to nothing

Raised: 2026-10-04 by the implementation review of DEPS-GRADLE-CATALOG-1B admission 1 (cycle 2; reviewer codex gpt-6-sol; F-DGC1B-ALIAS and its decision D-DGC1B-ARTIFACT-INTERPOLATION; slice stop condition (a)).

**The problem in plain words.** kafka's `gradle/dependencies.gradle:235` reads `scalaLogging: "com.typesafe.scala-logging:scala-logging_$versions.baseScala:$versions.scalaLogging"` and `build.gradle:1109` declares `libs.scalaLogging`. The candidate's alias reader reused `coordinate_group`, which rejects a `$` in the ARTIFACT segment, so this one alias of kafka's 98 direct-block aliases resolved to nothing and the field output carried `declared set may be incomplete: 1 alias reference(s) could not be resolved (build.gradle:1109 libs.scalaLogging: no catalog entry) — investigate` — honest about uncertainty, but the entry's group is plainly `com.typesafe.scala-logging`: the only value Java matching uses, and it is literal. D-DGC1B-ALIAS-MARKING-1 already rules the analogous case for the VERSION segment ("the interpolated version plays no part — the group is the literal prefix").

**Options (reward / risk, by usefulness to an agent net of misdirection).**
- A — the alias-map reader binds an entry when its group segment (the text before the first `:`) is a fully literal Maven coordinate segment and the artifact text is non-empty, whatever interpolation the artifact or version carries; an entry whose GROUP contains `$` (or is not a coordinate segment) resolves to nothing and is counted as `no catalog entry`; the 1A literal-coordinate reader (`coordinate_group`) is unchanged. Reward: the agent sees `com.typesafe.scala-logging` declared where the build declares it; kafka's 98/98 direct aliases bind; no investigation note for a mapping the compiler would apply. Risk: a group is treated as declared without the artifact being evaluated — the group is the only fact used, and the artifact's name was never consulted by any matching rule; the limit is stated.
- B — keep the reader fail-closed and amend the oracle to 97/98 with the unresolved alias named. Risk: a group visible in the map is reported as unresolved; the agent is sent to investigate a line that needs no investigation.
- C — defer. Risk: L13 undelivered.

Resolved: 2026-10-04 by the OPERATOR (in-place manager) as **A**, limited to the alias-map reader, as the reviewer recommended; overridable by the human. Tests bound: an interpolated artifact binds to its literal group; an interpolated group binds nothing and is counted; the literal-coordinate reader's tests unchanged.
