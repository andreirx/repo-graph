# D-RSR-ENTRY-CLIMB-1 — a sibling path binds only with declaration evidence: the enclosing module declares `mod <first>;` and the first segment is a module file; an undeclared first segment binds nothing

Raised: 2026-10-04 by the RUST-SELF-RESOLUTION-1 implementation reviewer (codex gpt-6-sol, admission 1 cycle 0; `DECISION_REQUIRED D-RSR-ENTRY-CLIMB-1`), after the builder's diagnostic replay found six false static edges.

**The problem in plain words.** Rule 2.1 (2)(d) of the slice said: a `use` whose first segment is not `crate`/`super`/`self` and names no declared Cargo package is read as a sibling path — module path + all segments — and walked down the L01 ladder, which shortens and ends at the crate entry file. For `rust/tools/xpart-probe/src/main.rs:22` `use std::collections::{BTreeMap, BTreeSet, HashMap};` that reads `std` as a sibling, finds no `src/std.rs`, shortens to nothing and lands on `src/lib.rs` — a static edge from the binary to its library root claiming the file defines `std`. Six such rows on repo-graph (every `std`/`scip` import written in a `main.rs` beside a `lib.rs`). A static edge to the wrong file is the one thing RG-REQ-002-L01 and RG-REQ-001-L03 forbid. The oracle missed them because its sibling selector copied the old classifier's basis instead of the contract's predicate.

**Options (the reviewer's and the builder's; reward / risk, by usefulness to an agent net of misdirection).**
- A — the hit must retain the sibling's first segment (no shortening past it). Removes the six rows and keeps the binds a file exists for. Risk: a file named like an external crate still binds without evidence that the module is declared here.
- B — bind only with module-declaration evidence: the enclosing module (the file, or the inline module around the `use`) declares `mod <first>;` — the extractor already records `rust_mod_decls` (name, `#[cfg(test)]`, `#[path]`, `inline_path`) on every Rust FILE node — and the first segment is a module file on the ladder. Reward: every sibling edge is backed by the declaration Rust itself resolves through; nothing an agent sees can point at a file that does not declare the module. MEASURED on the HEAD-built before-roots: repo-graph 972 sibling rows bind (889 the classifier had called "crate-internal", 101 it had called runtime modules — `use types::…` beside `mod types;` — and 8 it had called package dependencies), 1,298 undeclared first segments bind nothing (`std`, `serde`, names brought in by `use`), 0 false; zap-engine 119 bind, 84 nothing; codegraph 0 bind, 96 nothing. Risk: a module declared only through `#[path = "…"]` is skipped until RUST-PATH-ATTRIBUTE-1 (the decl fact carries the path; the ladder does not read it yet).
- C — mark file-list-only sibling hits INFERRED with candidates. Reward: a place to investigate without a certainty claim. Risk: changes L14's static outcome and every consuming partition for a class B binds with certainty.
- D — defer sibling binding. Risk: the sibling third of the slice undone.

Resolved: 2026-10-04 by the OPERATOR (in-place manager) as **B, with A's first-segment retention** (the reviewer's recommendation); the human may override. RG-REQ-006-L14 revision 3 states the rule; the slice's INPUT-2 carries it; the oracle selects sibling rows by the contract's predicate and the same declaration facts.

## What this record rules
- Stage 3.6 for a first segment that is not `crate`/`super`/`self` and names no declared Cargo package: bind only when the enclosing module's `rust_mod_decls` (matched on `inline_path` = the `use`'s `inlineModulePath`) contains the first segment AND `<enclosing>/<first>.rs` or `<enclosing>/<first>/mod.rs` is indexed; later segments may shorten, the first never; otherwise bind nothing and keep the classified row.
- A declared Cargo crate name whose candidate files are not indexed is a stage-3.5 miss and never enters stage 3.6 (unit-tested).
- The classifier's bare-head relativity applies to Rust-extractor rows only; a Python `import crate` keeps its classification (unit-tested).
