# D-AGENT-USEFULNESS-FRAME-1 — decisions are framed by usefulness to an agent net of misdirection; a reader-facing phrase restates the observed predicate, never a conclusion

Raised: 2026-10-03 by the human, on the fourth document cycle of IMPORTS-UNRESOLVED-REMAINDER-1 ("Frame the options in terms of how useful the output is to an agent"; then "Ok for D then and write this criteria down in repo-graph this is how we frame decisions").

## The framing rule (binding for every decision presented on repo-graph)
Every option is measured by what an agent can DO with the output, net of misdirection:
1. **What the agent learns per row/line** — the facts it can act on (here: an import is unconfirmed; the index's guess — ours / external / unknown; the candidate targets when recorded).
2. **What it can act on next** — the move the output licenses (open `deps`; find the target yourself; pick among listed candidates).
3. **How it can be misled** — every phrase that is true for most rows and false for some is a misdirection the agent cannot detect, because the numbers around it are right. A misdirection costs more than a missing hint: the agent follows it. (This is the failure class the v0.19.0 → v0.20.0 audits named "every number is real and the label is wrong".)
Options are ranked by usefulness NET of misdirection; "cheaper", "render-only" and "no reindex" are not rewards (human directive 2026-09-06).

## The phrase rule (the taxonomy that ends the cycle class)
A reader-facing phrase for a stored code (category, classification, basis, reason, coverage) **restates the predicate the code's assignment site tests — what was OBSERVED — never the conclusion that predicate suggests.** `specifier matches a tsconfig paths alias` (the classifier's test), not `the target is inside this repository` (an inference); `specifier is written as a local reference` (`./`, `../`, `crate::`, `super::`, `self::`, `:FILE`), not `relative target not indexed`; `same file name in 2 places`, not `no indexed file matches`. A phrase so written is true for every branch that assigns the code, by construction, and a reviewer checks it mechanically: phrase ≡ predicate at the assignment site (file:line named beside each phrase in the slice document). The inference the agent should draw is carried as the classification QUESTION (`this repository?` / `external library?` / `unknown`) — marked as a question — and by the candidates, never asserted in prose. Raw codes stay in `--json`.

## Why this record exists
Four document cycles of IMPORTS-UNRESOLVED-REMAINDER-1 (reviews 0–3) each found two or three reader phrases in the manager's vocabulary table that were false for some classifier branch (F-IUR-02, -05, -07, -09) or a coverage claim the evidence did not support (F-IUR-01, -08, -10). The phrases were conclusions written from the codes' names; the names do not reveal their semantics (CPP-ATTRIBUTE-MACRO-1A, TS-WORKSPACE-RESOLUTION-1 and CPP-INCLUDE-BASENAME-1 each widened a code's branch set). Three options were framed (full vocabulary and more cycles; a minimal row with codes JSON-only; the predicate echo) and ranked by agent usefulness net of misdirection: predicate echo > minimal row > full vocabulary > accept-with-corrections.

Resolved: 2026-10-03 by the HUMAN: **option D (predicate echo)** for IMPORTS-UNRESOLVED-REMAINDER-1, and the framing rule above recorded as the standing way decisions are framed on repo-graph.

## Scope ruling (human, 2026-10-03, appended): "We get buckets 2, 3 out of the way and use them to set the standard for how to wire and show the output"
The remaining bad grades of audit round eight were classified for the human as (1) fundamental capability gaps — call-graph resolution below 50 % on every language with a resolver, reader coverage (Gradle catalogs, Python routes, resource kinds, Scala), seed-model quality, large-repo latency; (2) wiring — data the store holds that a surface does not read, or two surfaces reading one snapshot differently (the per-file unresolved rows, the alias resolver that exists only on the never-served LiveGraph path, the repo-wide Summary under a module heading, doctor's authority mix, Java identity handling, the nested-build fold); (3) output formatting — help drift, stale cursors, rounding, unnamed remainders, economy; and (4) F grades that measure the corpus, not the tool (shallow clones, no coverage reports, nothing declared). The human ruled: clear buckets 2 and 3 first, and let those slices SET THE STANDARD for how an output surface is wired and shown. The standard, as the first exemplar (IMPORTS-UNRESOLVED-REMAINDER-1) states it: one storage reader for the fact → one raw DTO on the existing port → one attach site on the served answer → a render that states the remainder, the coverage, the unavailable and the unreadable states, with every reader phrase a predicate at its named site and every inference carried as a question. Bucket 1 is a horizon decision for the human after the queue's wiring items land, with the next audit's field numbers as its baseline.

## Options as presented (appended 2026-10-03 at the request of the RG-BOOTSTRAP-INPUT-12 review; the ruling above is unchanged)
Four options were put to the human after the fourth document cycle; the earlier sentence "three options were framed" counted A, B and D — C was the carried fourth. Each, as reward / risk, measured by usefulness to an agent net of misdirection:
- **A — keep the full reader vocabulary and run more review cycles.** Reward: the most useful row when every phrase is true — "matches a project alias" sends the agent to `tsconfig.json`, "matches a package dependency" to `package.json`, without opening `--json`. Risk: a phrase true for most rows and false for some is a misdirection the agent cannot detect; four cycles had found one such phrase per cycle with a dozen phrases unreviewed.
- **B — only claims that cannot be false (the import is unconfirmed; the index's guess as a question; the candidates); codes in `--json`.** Reward: never misleads; converges in one revision. Risk: the agent loses the "why" (for `@/…` it infers alias from the specifier; for a Rust `crate::` path it loses nothing true).
- **C — accept the document and carry the two open findings as text corrections.** Reward: no further document cycle. Risk: the agent gets A's row with two phrases already known false until the corrections land, and whatever the review had not yet found stays in.
- **D — keep the why, with every phrase restating the classifier's TEST, never its CONCLUSION (RULED).** Reward: the agent keeps A's actionable hint; the phrase is true for every branch by construction; the reviewer's check becomes mechanical (phrase ≡ predicate at the named site). Risk: about ten phrases still to word, one more cycle likely; the phrases are slightly more technical ("written as a local reference") than A's.
Ranking by usefulness net of misdirection: D > B > A > C. The human ruled D.
