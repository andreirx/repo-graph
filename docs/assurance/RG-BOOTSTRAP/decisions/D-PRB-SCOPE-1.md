## The amendments (each a finding the manager verified)
1. **No class-name rule.** The manager's rule (a) — "a receiver spelled like an indexed CLASS binds static to that class's method" — is unsound in Python (a parameter or local named like the class shadows it; the index holds no binding proof). Every untyped-receiver unique-name binding is INFERRED; a proven class receiver is PYTHON-CLASS-RECEIVER-1 (follow-up). Reward: no evidence-less static edge survives. Risk: none in the corpora measured (the rule had no witness).
2. **The self-call fall-through is in scope.** A `self.`/`cls.` call whose hierarchy walk ends without a hit must NOT reach the name-only fallback (the receiver IS typed by the enclosing class; the bare-name pool is not evidence for it): it stays unresolved with the basis `self_call_hierarchy_miss` and its candidate pool recorded. It is the same fallback branch this slice edits and the same defect class (RG-REQ-005-L03's "binds through its class hierarchy or stays unresolved"). Witness after: `callers ListMixin.extend` → `0 callers found; 266 inferred (name-only) — investigate with --include-inferred`; the 5 self calls appear on `explain` as unresolved with their basis. Reward: L03 holds instead of being recorded as a known failure. Risk: five django rows move from certain to unresolved (true), PYTHON-SELF-BINDING-1's bindings with a hit are untouched (its tests bound by name).
3. **Call-site anchors on caller rows.** `storage/src/queries.rs:741-805 find_direct_callers` reads `n.line_start` (the caller's declaration) where RG-REQ-005-L08 requires the call site; the newly exposed inferred rows and the certain rows alike carry `e.line_start` (the edge's call site: `autodetector.py:1737`, not the function's first line). Recorded under `changes` for L08 with its consequence: every `callers` row's line moves to the call site. Reward: the agent is sent to the call to investigate. Risk: a behaviour change on certain rows — the correct one; ANCHORS-EVERYWHERE-1's tests are bound by name.
4. **The inferred remainder rides every engine.** The remainder count (`find_symbol_inferred_callers/callees`) is a SQLite read the daemon attaches to `callers`/`callees`/`explain` whatever engine served the certain rows (LiveGraph or SQLite), so a mixed Python/TypeScript repository whose LiveGraph-served symbol is the target of an inferred Python call still states the remainder; a daemon test with the explain-serve spy proves it (django has 0 cross-language CALLS — fixture only). Reward: the answer does not depend on the backend (RG-REQ-002-L02). Risk: one read on the LiveGraph path.
5. **`path` states what it excluded.** `find_shortest_path` walks certain hops only; when no certain route exists and inferred hops would connect the endpoints, the result carries `inferred_hops_excluded: N` and the human line `no route through certain calls; N inferred hops exist — investigate`; `path --include-inferred` stays a follow-up. Reward: an absent route is never presented as proof of absence (RG-REQ-002-L04). Risk: one extra read on the no-route branch.

Also applied from the review: an L09 fixture (zero certain callers, nonzero unresolved same-name calls, the named count asserted); paired human/JSON and default/flag assertions for callees, explain and orient's symbol focus; every cargo oracle keeps cargo's exit status (`set -o pipefail`; a compile error fails the check).
