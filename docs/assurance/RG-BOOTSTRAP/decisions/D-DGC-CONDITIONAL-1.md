# D-DGC-CONDITIONAL-1 — A Gradle `dependencies` block the index cannot evaluate is marked on `deps list`, never dropped silently

Raised: 2026-09-24 by the second document review of DEPS-GRADLE-CATALOG-1A (reviewer codex gpt-6-sol, finding F-DGC-05 on RG-REQ-002-L11). The slice's revision 1 (answering F-DGC-02) made every `dependencies` block under a condition or callback (`if (…)`, `afterEvaluate`, `plugins.withId(…)`, `gradle.projectsEvaluated`) declare nothing — correct, the index cannot establish that the condition holds — but called the cost "a false-negative coverage limit" and left the consumer unchanged: `manifest_deps.rs:85-90` turns a script whose only declarations sit under such a block into a measured-empty declared set, and `deps list` then renders every observed import absent from that set as `undeclared N` with no clause saying the declared set is incomplete.
Resolved: 2026-09-24 by the OPERATOR — option A below. The human may override.

## The facts (verified on the three corpora at their pinned commits and on the source)
- Blocks under a condition or callback: grpc-java 5 (`build.gradle:190` and `:271` under `if (!project.hasProperty('errorProne') || errorProne.toBoolean())`, `:220` under `plugins.withId("java")`, `:467` under `plugins.withId("me.champeau.gradle.japicmp")`, `bom/build.gradle:15` under `gradle.projectsEvaluated`); kafka 0; spring-petclinic 0. They hold 0 literal `group:artifact` coordinates and 6 catalog references (`libraries.junit`, `libraries.mockito.core`, `libraries.truth`, …) — references 1A reads as nothing in any block (DEPS-GRADLE-CATALOG-1B), so 1A's declared sets on the three corpora are the same with or without the rule; the marking is what changes.
- `buildscript`/`pluginManagement` blocks (kafka 1, grpc-java 27) and task/extension blocks (`shadowJar { dependencies { … } }`: kafka 1, grpc-java 5) are NOT this class: L13 excludes the tooling classpath by name, and a shadow-jar `dependencies` block is a filter, not a declaration — both stay silently excluded.
- The visible uncertainty path that exists: `ManifestRecord { path, dir, ecosystem, error: Option<String> }` (`repo-index/src/manifest_deps.rs:274-290`) rides the `deps_manifests` diagnostics blob (`daemon-runtime/src/deps_headline.rs:30`); `error = Some(reason)` renders unknown-with-reason (`deps_ecosystem_presence.rs:87-93`, `deps_coverage.rs:101-112`) but DROPS the script's declared set — the wrong shape here, where the direct declarations are known.

## Options
- **A (ratified by the operator)** — an additive, backward-compatible marking on the parsed record. `ManifestRecord` gains `undetermined_blocks: Option<UndeterminedBlocks { count: u32, first: String }>` (`#[serde(skip_serializing_if = "Option::is_none")]`, like `error`), filled by the Gradle reader with the count of `dependencies` blocks it skipped under a condition or callback and the first one's `path:line`; the daemon's deps view sums the count over the view's parsed manifests into two additive envelope fields (`declared_undetermined_blocks: u64`, `declared_undetermined_note: String`, `#[serde(default)]` — the DEPS-ATTRIB-2 pattern at `rgr/src/presentation/deps_list.rs:120-160`); `deps list` renders, when the count is nonzero, the line `declared set may be incomplete: N conditional dependency block(s) not evaluated (build.gradle:190) — investigate` after the coverage line, and the `undeclared` label carries the suffix ` (declared set incomplete)`; JSON carries both fields. Tests: reader (a block under each head form yields the count and the first location; a direct block beside it is still declared), record serialization (absent key on zero), daemon aggregation (two manifests → summed count, first location of the first), rgr human and JSON (nonzero renders the line and suffix; zero renders neither; an older envelope without the keys renders as today). Field: grpc-java root row `5 … (build.gradle:190)`; kafka and petclinic no line. Reward: RG-REQ-002-L11's marking on the surface where the agent reads `undeclared`; the direct declarations stay known; one optional field and two envelope fields, each defaulting to today's rendering. Risk: the allocation grows by the daemon deps view and `deps_list.rs` with their tests; the count is a syntactic count of skipped blocks, not of declarations (stated in the line's wording — "blocks").
- **B** — record the script as a FAILED manifest when any conditional block is skipped. Reward: no new field. Risk: the direct declarations are dropped for the whole script — grpc-java's root row would lose its known set to mark five blocks that declare nothing 1A can read.
- **C** — keep revision 1 (a documented false negative, no marking). Reward: the smallest slice. Risk: `undeclared N` reads as certain where the index left a declaration site unevaluated — the class RG-REQ-002-L11 forbids; the reviewer has refused it once.

## Resolution
A. DEPS-GRADLE-CATALOG-1A's allocation adds the marking end to end (reader → record → daemon view → `deps list` human and JSON) with the tests above; the ship block quotes grpc-java `build.gradle:219-224` and the rendered line.
