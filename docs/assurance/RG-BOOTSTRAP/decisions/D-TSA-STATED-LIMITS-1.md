A knowable compiler binding is left unresolved — RG-REQ-006-L04 asks for the language's resolution. (specifier matches a tsconfig paths alias)`) and the index prints one warning naming the file and the config. The agent-facing row does not say WHY the binding was not made — RG-REQ-002-L11 asks for the reason on the agent-facing surface.
